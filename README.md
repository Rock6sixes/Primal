a vibe coded rain world mod for tough character versions

**How to install**

1. From releases download latest version (the Primal.zip file)

2. Extract file

3. You should now have a folder called Primal with 2 folders called plugins and scenes inside it

4. Move this folder into your Rain World installation folder > RainWorld_Data > StreamingAssets > mods

(For steam users, the installation folder is under steamapps > common, or you can find it by right clicking game in Steam, clicking Manage and then Browse Game Files)

5. Then just run the game and enable it in Remix!
